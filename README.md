# Nido de recetas

App de recetas para el robot de cocina **Moulinex Clickchef**, al estilo de Cookidoo.

- Recetas con foto, ingredientes y pasos, y modo cocina paso a paso con temporizador y checklist.
- Lista de la compra por receta y lista normal con buscador de precios de Mercadona.
- Historial de platos cocinados con valoraciones, favoritas y recetas propias.
- Guía de la Clickchef: programas, accesorios y tablas.

Es una página estática: abre `index.html` o publícala con GitHub Pages. Los datos del usuario se guardan en el navegador.
